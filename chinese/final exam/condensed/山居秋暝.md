# 山居秋暝 — 王維

#山居秋暝 #HKDSE

---

## 作者簡介

**王維**（公元 701–761），字**摩詰**，祖籍太原祁州（今山西省祁縣），從父親起遷居蒲州（今山西省永濟縣）。年青時有才名，二十多歲中進士後開始當官，曾任太樂丞，後貶官濟州。曾在淇上、嵩山一帶隱居，開元年間任右拾遺。唐朝天寶年間在**終南山**和**輞川**（今陝西省藍田縣南）購置別墅，閒時前往居住。

- 在**繪畫、音樂、詩歌**等方面造詣很高，**山水田園詩**成就尤其突出
- 信奉佛教，詩作常蘊含**禪趣**，有「**詩佛**」之稱
- 蘇軾讚譽：「**詩中有畫**」

---

## 背景資料

這首詩是王維居於**輞川**時所寫。「**山居**」即他所住的輞川別墅。王維晚年在此處過着**半官半隱**的生活。詩中描寫秋天傍晚山村的秀美景色，描繪詩人居於山中的恬淡生活。

---

## 原文

> 空山新雨後，天氣晚來秋。
> 明月松間照，清泉石上流。
> 竹喧歸浣女，蓮動下漁舟。
> 隨意春芳歇，王孫自可留。

**體裁**：五言律詩（共四十字）

> [!tip] 五言律詩體制特色
> 全詩八句，每句五字。分四聯：首聯、頷聯、頸聯、尾聯。其中**頷聯**和**頸聯**必須**對偶工整**。雙數句句末必須**押韻**。

---

## 逐句分析

### 首聯：空山新雨後，天氣晚來秋。

| 要素 | 分析 |
|------|------|
| 意境 | 空山之中剛下過一場雨，傍晚時分秋涼襲人 |
| 手法 | **平淡自然，絕無雕飾**，點出季節、時間、環境 |
| 效果 | 十個字描繪出山中秋色的**清新疏淡**，令人宛如呼吸到雨後清爽濕潤而略帶涼意的空氣 |
| 描寫角度 | **遠眺、仰視**（「空山」一詞概括山中環境，為遠望；由「天氣」二字可知仰望天色） |
| 描寫手法 | **感官描寫**：「空山新雨後」運用**視覺描寫**，描繪雨後的清幽山景；「天氣晚來秋」運用**觸覺描寫**，描述傍晚時分雨後舒適、清涼的初秋天氣 |
| 呼應詩題 | 「空山」二字呼應詩題「**山居**」，點出詩人身處的地點；「晚」及「秋」兩字呼應詩題「**秋暝**」，點出秋天季節及晚上時分 |
| 描寫景象 | 雨後、入暮山間美好的秋景。「空山」概括山中的幽靜、寧謐，加上剛剛下過雨，讓人感到一片清幽、寧靜，眼前是安祥舒適、美好清新的景象 |
| 詩人心情 | 愉快、舒暢。詩人信奉佛教，「**空**」的含義是**去除執念**。「空山」並非真的空無一物、空無一人，但人在山中，既沒有塵心俗慮，亦沒有妄念與執著，身處全無俗氣的「空山」中，又遇上秋涼的下雨天後，感到清新怡人 |

> [!tip] 考試重點
> 首聯以「**感官描寫**」為主要手法：視覺（山景）+ 觸覺（秋涼）。詩人心情愉快，「空」字蘊含佛教「去除執念」之意。

### 頷聯：明月松間照，清泉石上流。

| 要素 | 分析 |
|------|------|
| 上句 | 「明月松間照」——從**天上**寫，仰視／遠眺。月和松的關係畫出背景：皎潔明月襯出剪影般墨綠松林 |
| 下句 | 「清泉石上流」——從**地下**寫，俯視／近觀。泉水流過白石，反映泉水清澈，激盪清響 |
| 手法 | **視覺描寫**（構圖取景），以概括筆墨描繪山中夜色 |
| 多角度描寫 | 由遠而近、由上而下地刻劃山村秋景，先寫遠處高掛的明月，再近觀月下的高聳松林及低處在石上流動的清泉。這種多角度景物描寫令詩歌內容更見豐富，條理層次更見分明，讓讀者清楚掌握山林四周的環境特點 |
| 效果 | 用最簡單的構圖概括山中秋夜主要特徵，突顯**清朗爽淨**的基調 |
| 地位 | 王維名句，經常被後世山水畫家用來**題畫** |

> [!tip] 考試重點
> 此聯體現王維「**詩中有畫**」的特點，以畫家眼光構圖取景，上句寫天、下句寫地，形成鮮明完整的畫面。

> [!tip] 以動襯靜（重要考點）
> 此聯運用了「**以動襯靜**」的手法突出山居的幽靜。作者以石上潺潺流動的清泉的細微動態**反襯**山中幽靜的傍晚景色，萬物如明月、松樹處於靜止狀態的景象，突出山林環境的空靈和幽靜。
> - **答題句式**：必須運用「**以……反襯……突顯……**」的句式作答，否則不給分。

> [!tip] 自然景物寄寓
> 「**明月**」「**清泉**」明淨澄澈，「**青松**」挺拔剛直，作者厭倦官場生活，不欲與官場中人為伍，潔身自愛，詩人藉此等景物寄寓自己**孤高不群的高潔情懷**。

### 頸聯：竹喧歸浣女，蓮動下漁舟。

| 要素 | 分析 |
|------|------|
| 上句 | 「竹喧歸浣女」——從**岸上**寫，**聽覺**落筆：先聞竹林傳來談笑聲，再點出浣衣女歸來（**聞聲而見人**） |
| 下句 | 「蓮動下漁舟」——從**水裏**寫，**視覺**落筆：蓮花蓮葉搖動，原來是漁舟歸來 |
| 感官描寫 | **視覺描寫及聽覺描寫**（兩種感官交織） |
| 手法 | **動態描寫**；按照感知事物的自然順序構句（先聞/見 → 後辨別） |
| 出處 | 受庾信「竹動蟬爭散，蓮搖魚暫飛」（《詠畫屏風詩》其二十三）啟發，但王維更進一步融入心理活動 |
| 效果 | 繪聲繪色，使全詩在**色彩和聲響的交織**中顯現自然多樣的**動態美**；與前兩聯靜景相映襯，避免冷清平淡 |

> [!tip] 首頸聯呼應
> - **與首聯呼應**：「竹喧歸浣女」的「**歸**」字，呼應「天氣晚來秋」的「**晚來**」，點出傍晚正是洗衣的女子歸來的時間。
> - **與頷聯呼應**：「竹喧歸浣女」的「**浣女**」兩字，呼應「清泉石上流」，點出山中有清泉，洗衣的女子應是在清澈的溪泉洗衣。

> [!tip] 倒裝句式
> 這兩句都是**倒裝句**，原序為「**竹喧浣女歸**」和「**蓮動漁舟下**」。從律詩的體制來說，雙數句句末須押韻，運用倒裝句將「**女**」和「**舟**」置句末，就是為了聯末的押韻需要，使詩歌符合五言律詩的體例要求。

> [!tip] 考試重點
> 此聯的**感知順序構句法**是重要考點：先寫所聞/所見（竹喧、蓮動），再寫分辨清楚的人事景物（浣女、漁舟），將詩人審美觀不露痕跡地融入景物描寫。

> [!tip] 「蓮動下漁舟」與主題的關係
> 「蓮動下蓮動下漁舟」敘寫傍晚時漁舟順流而下的情況，表現出山中人生活勤勞純樸。通過描繪這「日出而作、日入而息」的鄉間生活，正正反映作者對寧靜純樸生活的嚮往，以及離開仕途、歸隱山間的決心。

### 尾聯：隨意春芳歇，王孫自可留。

| 要素 | 分析 |
|------|------|
| 釋義 | 任憑春天芳草自然凋謝，秋色仍然很美，王孫自可留在山中 |
| 典故 | **反用**《楚辭‧招隱士》：「王孫遊兮不歸，春草生兮萋萋」「王孫兮歸來，山中兮不可以久留」 |
| 原典原意 | 春草萋萋，外面環境危險，希望王孫歸來，不要在山中久留（山中環境寂寞可怕，不能久留，要招隱士回家） |
| 本詩用法 | 見秋色而希望隱居，表達對**官場生活的厭倦**和對**隱居生活的嚮往** |
| 效果 | 常見典故經活用，感覺格外**新鮮** |

> [!tip] 考試重點
> **典故活用**是高頻考點。此聯反用《楚辭》原意，表達山中美景令人留戀，不必歸去。

> [!tip] 反用典故評分準則
> 1. 須將**原典內容列出**：春草萋萋、外面環境危險、希望王孫歸來、不要在山中久留
> 2. **反用意思**（把原典意思反過來）
> 3. **文本依據準確**：山林春花凋謝，但明月、清泉等景色與山村洗衣女、漁夫簡樸的人事生活仍然吸引
> 4. **作者自願留下**
> 5. **抒發情懷**：喜愛山林美景、嚮往山林生活以及厭倦官場生活，三者俱存

## 重點賞析

### 意境

全詩營造了**空山秋夜清幽明淨**的意境，有靜有動，有聲有色，猶如一首優美的山村抒情小夜曲。

### 主題

| 層面 | 內容 |
|------|------|
| 表層 | 描寫秋天傍晚雨後山村的秀麗風光 |
| 深層 | 反映詩人對**官場生活的厭倦**，表達對**隱居生活的嚮往** |

### 藝術技巧

1. **詩中有畫**：頷聯以畫家眼光構圖，選取最有特徵的景物
2. **動靜結合**：首聯、頷聯為靜景 → 頸聯轉為動景，相互映襯
3. **感官交織**：視覺（明月、清泉、蓮動）+ 聽覺（竹喧、泉聲）
4. **構圖取景**：天上→地下、岸上→水裏，層次分明
5. **典故活用**：反用《楚辭‧招隱士》，翻新出奇
6. **感知順序構句**：先聞/見 → 後辨別，符合人感知事物的自然順序
7. **語言風格**：清新自然，平淡中見功力
8. **多角度描寫**：頷聯由遠而近、由上而下，內容豐富，條理分明
9. **以動襯靜**：頷聯以清泉流動反襯山林幽靜，頸聯以浣女漁舟動態反襯環境空靈

### 關鍵字詞

| 字詞 | 意義 | 作用 |
|------|------|------|
| **空** | 空寂、空蕩 | 點出山之幽靜；佛教「去除執念」之意 |
| **新** | 剛剛 | 強調雨後清新 |
| **喧** | 嘈雜聲 | 以聲寫動，聞聲見人 |
| **歇** | 停歇、凋謝 | 指春花凋零 |
| **隨意** | 自然而然 | 表達順其自然的態度 |

## 考試重點

> [!tip] 必考知識點
> 1. **體裁**：五言律詩（八句、五字、四聯、頷頸聯對偶工整、雙數句押韻）
> 2. **作者**：王維，字摩詰，「詩佛」
> 3. **寫作背景**：居輞川別墅，半官半隱
> 4. **主旨**：描寫山村秋景，表達隱居之志、厭倦官場
> 5. **首尾呼應**：「歸」字與「晚來秋」相呼應
> 6. **典故**：反用《楚辭‧招隱士》
> 7. **詩中有畫**：蘇軾對王維詩的讚譽
> 8. **胡應麟評語**：「清而秀」

> [!tip] 高分答題要訣
> - 分析頷聯時強調「**構圖取景**」和「**詩中有畫**」
> - 分析頸聯時強調「**感知順序構句法**」和「**動靜結合**」
> - 尾聯答題必答「**反用典故**」及所表達的**隱逸情懷**
> - 以動襯靜答題必須運用「**以……反襯……突顯……**」的句式，否則不給分

> [!tip] 頸聯動靜結合評分準則
> 須以反襯句式「以……反襯……突顯……」作答，否則不給分。文本依據須包括：
> 1. 洗衣服的女子歸來經過竹林時發出的喧鬧聲（1 分）
> 2. 漁舟順流而下划過令蓮葉搖動的動態（1 分）
> 3. 反襯（1 分）
> 4. 山中晚上萬物如明月、清泉所處的靜止狀態（1 分）

> [!tip] 自然景物寄寓
> 首聯及頷聯選取的自然景物：「**明月**」「**青松**」「**清泉**」。明月、清泉明淨澄澈，青松挺拔剛直，作者厭倦官場生活，不欲與官場中人為伍，潔身自愛，藉此等景物寄寓自己**孤高不群的高潔情懷**。

> [!tip] 感官描寫總結
> - 首聯：視覺描寫（山景）+ 觸覺描寫（秋涼）
> - 頷聯：視覺描寫（月、松、泉）
> - 頸聯：聽覺描寫（竹喧）+ 視覺描寫（蓮動）

## 常見題型

### 1. 釋義題

- 解釋「暝」「喧」「浣女」「歇」「王孫」等字詞
- 翻譯全詩或指定詩句

### 2. 賞析題

- 分析頷聯如何體現「詩中有畫」的特點
- 比較頸聯與庾信詩句的異同
- 分析全詩動靜結合的手法
- 評析尾聯典故活用的效果

### 3. 主旨題

- 詩人通過描寫山中秋景表達了怎樣的思想感情？
- 尾聯如何點明全詩主旨？

### 4. 結構題

- 分析首尾呼應關係
- 說明頸聯與首聯、頸聯的呼應關係（「歸」→「晚來」、「浣女」→「清泉」）
- 說明頸聯倒裝句式的作用（為了押韻需要）
