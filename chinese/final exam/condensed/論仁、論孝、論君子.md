# 論仁、論孝、論君子 — HKDSE 溫習精要

> [!tip] 考試重點
> 本文選自《論語》，共十六則語錄，分為「論仁」（四則）、「論孝」（四則）、「論君子」（八則）三部分。須掌握每章原文、注釋、要旨，以及仁、孝、君子三者的內涵與相互關係。

---

## 作者簡介

**孔子**（公元前551或552 – 公元前479），名丘，字仲尼，春秋末期魯國人，儒家學派創始人。

- **政治生涯：** 曾任魯國司寇（管刑政），頗有政績。後因不滿魯國大夫季桓子接受齊國女樂、不聽政、不守禮的行為，離開魯國，周遊宋、衛、陳、蔡、齊等國，宣揚政治主張，可惜不獲採納。
- **晚年：** 返回魯國，潛心著述及講學，編訂《詩》、《書》、《禮》、《易》、《春秋》等文獻。
- **思想核心：** 強調**仁愛**，重視**禮樂**，主張以德服人，施行仁政，反對殘暴統治、武力征伐，成為中國文化的正統。
- **教育貢獻：** 開啟私人講學之風，使教育由上層社會走向平民化。主張**「有教無類」**、**「因材施教」**，誨人不倦，相傳有弟子三千，賢者七十二人。
- **《論語》：** 弟子及其再傳弟子將其言行輯錄而成。《論語》屬**語錄體**，以記言為主，記述孔子與弟子及時人的日常對答和談話，是反映孔子思想的主要典籍和依據。

### 《論語》的編定

自唐代以來，很多學者推斷《論語》由**曾參的學生**所編定。楊伯峻認同此說，提出兩個理據：

1. 《論語》對曾參無一處不稱「子」，且記載其言行特別多。
2. 在孔子弟子中，曾參最年輕，且有一章記載曾參臨死前對孟敬子說的一段話，確實為曾參弟子所記。

## 背景資料

- 《論語》為**語錄體**，以語錄和對話的形式寫成，記載了孔子及其弟子的言行。
- 全書共**二十篇**，各篇一般以第一章的首二、三字作為篇名。
- 各章章節短小，內容獨立，直接記錄人物言論，語言精煉，含意深遠。
- 《論仁、論孝、論君子》輯錄了《論語》中與**仁**、**孝**、**君子修為**相關的若干條目，既表現出「仁」這種儒家倫理品德的豐富內涵，也勾勒了孔子心目中「仁者」的形象和修養，行文質樸，充滿睿智。

### 主旨

- 「論仁」部分：談論孔子學說的中心思想「仁」，談如何實踐仁的行為與原則，以及仁者的心境。
- 「論孝」部分：談論如何實踐善事父母。
- 「論君子」部分：指出君子的品德修養及做人處事的態度，以及說明君子與小人的分別。

## 各章原文

### 【論仁】

**第一章**（《里仁》第四）
> 子曰：「不仁者，不可以久處約，不可以長處樂。仁者安仁，知者利仁。」

**第二章**（《里仁》第四）
> 子曰：「富與貴，是人之所欲也；不以其道得之，不處也。貧與賤，是人之所惡也；不以其道得之，不去也。君子去仁，惡乎成名？君子無終食之間違仁，造次必於是，顛沛必於是。」

**第三章**（《顏淵》第十二）
> 顏淵問仁。子曰：「克己復禮為仁。一日克己復禮，天下歸仁焉。為仁由己，而由人乎哉？」
> 顏淵曰：「請問其目。」子曰：「非禮勿視，非禮勿聽，非禮勿言，非禮勿動。」
> 顏淵曰：「回雖不敏，請事斯語矣。」

**第四章**（《衞靈公》第十五）
> 子曰：「志士仁人，無求生以害仁，有殺身以成仁。」

### 【論孝】

**第五章**（《為政》第二）
> 孟懿子問孝。子曰：「無違。」
> 樊遲御，子告之曰：「孟孫問孝於我，我對曰，無違。」
> 樊遲曰：「何謂也？」子曰：「生，事之以禮；死，葬之以禮，祭之以禮。」

**第六章**（《為政》第二）
> 子游問孝。子曰：「今之孝者，是謂能養。至於犬馬，皆能有養；不敬，何以別乎！」

**第七章**（《里仁》第四）
> 子曰：「事父母幾諫，見志不從，又敬不違，勞而不怨。」

**第八章**（《里仁》第四）
> 子曰：「父母之年，不可不知也。一則以喜，一則以懼。」

### 【論君子】

**第九章**（《學而》第一）
> 子曰：「君子不重則不威；學則不固。主忠信。無友不如己者。過則勿憚改。」

**第十章**（《述而》第七）
> 子曰：「君子坦蕩蕩，小人長戚戚。」

**第十一章**（《顏淵》第十二）
> 司馬牛問君子。子曰：「君子不憂不懼。」
> 曰：「不憂不懼，斯謂之君子已乎？」子曰：「內省不疚，夫何憂何懼？」

**第十二章**（《顏淵》第十二）
> 子曰：「君子成人之美，不成人之惡。小人反是。」

**第十三章**（《憲問》第十四）
> 子曰：「君子恥其言而過其行。」

**第十四章**（《衞靈公》第十五）
> 子曰：「君子義以為質，禮以行之，孫以出之，信以成之。君子哉！」

**第十五章**（《衞靈公》第十五）
> 子曰：「君子病無能焉，不病人之不己知也。」

**第十六章**（《衞靈公》第十五）
> 子曰：「君子求諸己，小人求諸人。」

## 逐章分析

### 【論仁】逐章分析

#### 第一章：不仁者不可以久處約

| 人物 | 態度 | 內涵 |
|------|------|------|
| **不仁者** | 不可以久處約，不可以長處樂 | 失其本心，沒有自我克制能力。久處窮困則苟且放蕩、不擇手段；久處安逸則驕奢淫縱，不能自守。 |
| **仁者** | 安仁 | 心與仁為一，純乎天理，不待勉強，能克制私欲，安份素位而行。不以約、樂繫於心，任何環境下都能堅持操守。 |
| **智者** | 利仁 | 心未能即與仁為一，深知篤好，以仁為利。利用仁德達到目的，有「機心」的功利表現。 |

> [!tip] 考試重點
> **仁者安仁 vs 智者利仁：** 仁者實行仁德便心安（無愧於心、心安理得），安貧樂道；智者認識仁德的好處，利用仁德獲取利益。兩者動機不同。

**連結對比：** 《岳陽樓記》中古仁人「不以物喜，不以己悲」，超然物外，正是仁者的寫照。蘇東坡《赤壁懷古》貶謫黃州仍豁達灑脫，亦可為例。

#### 第二章：富與貴，是人之所欲也

**要旨：** 仁者對富貴貧賤的取捨之道——時刻堅持仁德，方為君子。

- **富貴：** 不以正當方法得到，不接受。
- **貧賤：** 不以正當方法擺脫，不逃避。
- **君子去仁，惡乎成名：** 離開了仁德，怎能成就君子之名？
- **無終食之間違仁：** 片刻不離仁德，倉卒急迫、顛沛流離時亦然。

> [!tip] 考試重點
> 本章以**對比**手法（富貴 vs 貧賤）說理，強調君子能潔身自愛，時刻堅守仁德，從不違背。用**反問句**「君子去仁，惡乎成名」加強語氣。

#### 第三章：顏淵問仁

**要旨：** 「克己復禮」是求仁之道。

- **綱領：** 克己復禮為仁——抑制自己，使言語行動都合於禮。
- **條目（目）：** 非禮勿視、非禮勿聽、非禮勿言、非禮勿動。
- **為仁由己：** 實踐仁德要憑自己，不能靠別人。

**課文結構：**

| 層次 | 內容 | 意義 |
|------|------|------|
| 行止（綱領） | 克己復禮為仁 | 嚴守行仁的綱領 |
| 條目 | 非禮勿視、聽、言、動 | 實踐行仁的具體方法 |

> [!tip] 考試重點
> **領語式論述結構：** 先引領出關鍵詞語「克己復禮」，再進行解釋。好處是論述對象明確，一目了然。**排比句**「非禮勿視，非禮勿聽，非禮勿言，非禮勿動」增強氣勢。

#### 第四章：殺身成仁

**要旨：** 這是仁的最高層次——凸顯成仁的重要和艱巨。

- **無求生以害仁：** 沒有為保存性命而損害仁德的。
- **有殺身以成仁：** 只有犧牲自己以成全仁德的。

> [!tip] 考試重點
> 本章以**對偶句**「無求生以害仁，有殺身以成仁」展現仁者為仁不惜犧牲生命的崇高精神。

#### 綜合「論仁」四章

仁者**安貧處樂**，無失本心，不管身處怎樣的境況，無時無刻都堅持實踐仁德，不因求生而害仁，相反能殺身成仁；而修養仁德的方法，就是**克制私欲**，視、聽、言、動皆合於禮。

### 【論孝】逐章分析

#### 第五章：孟懿子問孝——孝與禮的關係

**要旨：** 無違於禮就是孝，子女侍奉父母，不論父母生前和死後，都要合乎禮節處理。

- **無違：** 不要違背禮節。
- **生，事之以禮：** 父母健在，依規定的禮節侍奉他們。
- **死，葬之以禮，祭之以禮：** 父母死了，依規定的禮節埋葬他們，祭祀他們。

**孝與禮的關係：**
- 「孝」是「禮」的內在精神構成之一。
- 「禮」是「孝」的外在表現之一。

**「生，事之以禮」具體表現：**

| 行為 | 說明 |
|------|------|
| 冬則溫、夏則清、晨則省、昏則定 | 用心體貼父母起居 |
| 父母呼，應勿緩；父母命，行勿懶 | 及時回應、不拖延 |
| 或飲食、或坐走、長者先、幼者後 | 事事尊重父母 |
| 親有疾、藥先嘗、晝夜侍、不離床 | 盡心照顧生病父母 |
| 稱尊長、勿呼名、對尊長、勿現能 | 謙虛有禮 |
| 父母在，不遠遊，遊必有方 | 陪伴父母，遠行須告知去處 |

**「死，葬之以禮，祭之以禮」具體表現：**
- **慎終追遠：** 父母臨終時，子女慎誠待側，躬自護理。
- **三年之喪：** 守孝期間常追思感懷，起居須調整，戒絕酒肉。
- **喪盡禮、祭盡誠、事死者、如事生：** 辦喪事哀戚合乎禮節，春秋二祭依禮誠祭，視死如生。

> [!tip] 考試重點
> **清代喇沙里、陳廷敬《日講四書解義》引述：** 「所謂無違，止是不違乎禮，禮即天理之節文也……自始至終，禮之所當為者，不敢不為……禮之所不當為者，即不敢為……此之謂無違，此之謂孝。」

#### 第六章：子游問孝——敬的重要性

**要旨：** 以飼養動物作喻，闡述如對父母養而不敬，將無異於飼養動物。**「敬」是孝的最重要表現**，為人子女者須用尊敬的態度奉養父母。

- **今之孝者，是謂能養：** 現在的孝道只說能養活父母。
- **犬馬皆能有養：** 犬馬都能得到飼養。
- **不敬，何以別乎：** 若不心存敬意，養活父母跟飼養犬馬有甚麼分別？

**能養 vs 能養+能敬：**

| | 犬馬 | 人 |
|---|---|---|
| 能養 | ✓ | ✓ |
| 能敬 | ✗ | ✓ |

> [!tip] 考試重點
> 楊伯峻《論語譯注》認為「犬馬皆能有養」應解作：犬馬都能夠得到飼養，若不存心嚴肅地孝順父母，那養活父母和飼養犬馬就沒有分別。

#### 第七章：事父母幾諫——委婉規勸

**要旨：** 如遇父母犯錯，子女要以委婉態度規勸父母正視錯誤，如意見未能獲接納，不應埋怨父母。

- **幾諫：** 點到即止地指出，婉轉地勸止。
- **見志不從，又敬不違：** 意見未獲接納，仍然恭敬地不冒犯。
- **勞而不怨：** 雖然擔憂，但不抱怨。

**延伸連結：**
- 葉公語孔子：「吾黨有直躬者，其父攘羊，而子證之。」孔子曰：「父為子隱，子為父隱，直在其中矣。」
- 桃應問孟子：舜為天子，皋陶為士，瞽瞍殺人，舜如何處理？孟子曰：「舜視棄天下，猶棄敝蹝也。竊負而逃，遵海濱而處，終身欣然，樂而忘天下。」——可見舜是孝子。

#### 第八章：父母之年——關心父母

**要旨：** 孝的另一表現是將父母的年歲時刻記在心上，表示對父母的關愛。

- **一則以喜：** 因父母高壽而歡喜，仍有機會侍奉孝順。
- **一則以懼：** 因父母年事已高，害怕他們患病或離世，沒機會再孝敬。所謂「樹欲靜而風不息，子欲養而親不在」。

#### 綜合「論孝」四章

行孝的表現包括：

1. **事親而不違禮**——父母在生時以禮侍奉，死後依禮安葬和祭祀。
2. **對父母心懷敬意**——不僅能養，更要能敬。
3. **委婉規勸**——父母有過失，必委婉規勸。
4. **多加關心**——時刻記掛父母的年歲，為長壽而高興，為衰老而憂戚。

### 【論君子】逐章分析

#### 第九章：君子不重則不威——君子應具備的四種品德

| 方面 | 原文 | 說明 |
|------|------|------|
| **儀表** | 君子不重，則不威，學則不固 | 不莊重就沒有威嚴，所學也不穩固 |
| **處世** | 主忠信 | 以忠誠、信實為主 |
| **交友** | 無友不如己者 | 不結交品德不及自己的人（一說不同道的人） |
| **改過** | 過則勿憚改 | 有了過錯就不要怕改正 |

**「無友不如己者」兩種解釋：**

1. 君子不會跟不如自己的人交朋友——希望找勝過自己的人為友，作為學習效法的對象。
2. 君子不會跟與自己不同道的人交朋友。

> [!tip] 考試重點
> 「學則不固」有兩解：一、即使讀書，所學也不會牢固；二、學了就不會閉塞淺陋。

#### 第十章：君子坦蕩蕩

**要旨：** 君子與小人心境不同。

| | 君子 | 小人 |
|---|---|---|
| 心境 | 坦蕩蕩（心胸舒坦寬廣） | 長戚戚（經常局促憂愁） |

**君子能「坦蕩蕩」的原因：**
- 看重道義，不計較利害得失，故心感坦然。
- 注重實踐，不崇尚空言，不言過其實。

#### 第十一章：司馬牛問君子

**要旨：** 君子問心無愧，無憂無懼。

- **君子不憂不懼：** 凡事依禮而行，沒做過不合乎仁義的事，問心無愧。
- **內省不疚：** 自我反省而不感到羞愧，便沒有甚麼可憂愁可恐懼。

> [!tip] 考試重點
> 君子重視個人品格，為自己犯錯而憂愁恐懼，故能常常自我反省。當君子自我反省而不感羞愧的話，便沒有甚麼值得憂愁恐懼了。

#### 第十二章：君子成人之美

**要旨：** 君子能成人之美，鼓勵他人為善，不助人為惡；小人則相反，助紂為虐。

| | 君子 | 小人 |
|---|---|---|
| 行事 | 成人之美，不成人之惡 | 反是（助人為惡） |

#### 第十三章：君子恥其言而過其行

**要旨：** 君子重視**言行一致**，強調慎言力行，實踐多於空談，態度認真、穩重。

#### 第十四章：君子義以為質

**要旨：** 君子行事、言談，皆以「義」為依歸、首要考慮原則。

| 層次 | 原文 | 說明 |
|------|------|------|
| 原則 | 義以為質 | 以合宜為原則 |
| 行為 | 禮以行之 | 依禮節實行 |
| 言語 | 孫以出之 | 用謙遜的言語說出 |
| 態度 | 信以成之 | 用誠實的態度完成 |

#### 第十五章：君子病無能焉

**要旨：** 君子重視自己的真材實學、才能學問，不求虛名，不重視別人是否理解自己。

- 只擔心自己力有不逮，不擔心自己懷才不遇。
- 有麝自然香，已問心無愧。

#### 第十六章：君子求諸己

**要旨：** 君子和小人的自我要求不同。

| | 君子 | 小人 |
|---|---|---|
| 責任感 | 求諸己——律己以嚴，勇於承擔 | 求諸人——苛責別人，推卸責任 |

#### 綜合「論君子」八章

君子處事莊重認真，知錯能改；為人謙遜誠實，言行一致，堅守禮義；律己以嚴，時加反省；待人以寬，成人之美；跟志同道合的人交朋友；內心坦蕩舒泰，不憂不懼。「君子」的品德情操，是孔子心目中的模範。

## 重點賞析

### 藝術手法

**1. 語錄體特色**
- 對話生動真實，富現場感，可信度高。
- 文字簡煉，含意深遠。

**2. 修辭手法**

| 手法 | 例句 |
|------|------|
| **對偶** | 「無求生以害仁，有殺身以成仁」；「君子坦蕩蕩，小人長戚戚」 |
| **反問** | 「君子去仁，惡乎成名」；「為仁由己，而由人乎哉」；「不敬，何以別乎」 |
| **排比** | 「非禮勿視，非禮勿聽，非禮勿言，非禮勿動」 |
| **對比** | 君子對「富與貴」和「貧與賤」的態度；飼養犬馬 vs 侍奉父母；君子 vs 小人的操行 |

**3. 論述結構**

- **領語式結構：** 先引領出關鍵詞語，再進行論述。如「顏淵問仁。子曰：『克己復禮為仁。』」下文便就「克己復禮」進行解釋。又如「孟懿子問孝。子曰：『無違。』」下文即闡述甚麼是「無違」。好處是論述對象明確，一目了然。

**4. 對比說理**
- 以對比說理是《論語》的一項特點，通過對比，讓讀者更了解孔子的主張。

## 核心概念

### 仁

**仁**是孔子學說的中心思想，內涵豐富：

| 層面 | 內容 |
|------|------|
| **本質** | 仁者安仁——心與仁為一，純乎天理 |
| **修養方法** | 克己復禮——抑制私欲，視聽言動皆合於禮 |
| **實踐原則** | 時刻堅持，造次必於是，顛沛必於是 |
| **最高境界** | 殺身成仁——為仁德不惜犧牲生命 |
| **取捨之道** | 富貴不以道得之不處，貧賤不以道得之不去 |

### 孝

**孝**是儒家倫理的重要組成：

| 層面 | 內容 |
|------|------|
| **核心原則** | 無違——不違背禮節 |
| **態度** | 敬——不僅能養，更要心懷敬意 |
| **對待過錯** | 幾諫——委婉規勸，見志不從又敬不違 |
| **時刻關心** | 父母之年，不可不知，一則以喜，一則以懼 |
| **生前事奉** | 事之以禮——用心體貼、及時回應、尊重長輩 |
| **死後安葬** | 葬之以禮、祭之以禮——慎終追遠，視死如生 |

### 君子

**君子**是孔子心目中的理想人格：

| 層面 | 內容 |
|------|------|
| **莊重威儀** | 不重則不威，學則不固 |
| **處世原則** | 主忠信，義以為質，禮以行之，孫以出之，信以成之 |
| **交友之道** | 無友不如己者——慎擇朋友 |
| **改過態度** | 過則勿憚改 |
| **言行一致** | 恥其言而過其行 |
| **自省精神** | 內省不疚，不憂不懼 |
| **待人接物** | 成人之美，不成人之惡 |
| **自我要求** | 求諸己，不求諸人；病無能焉，不病人之不己知 |
| **心境** | 坦蕩蕩——心胸舒坦寬廣 |

### 仁者與君子的關係

| 範疇 | 仁者 | 君子 | 相同之處 |
|------|------|------|----------|
| **價值觀** | 無求生以害仁，有殺身以成仁 | 無終食之間違仁，造次必於是，顛沛必於是 | 都堅守仁 |
| **行為準則** | 克己復禮為仁 | 義以為質，禮以行之 | 都以禮作為行事準則 |
| **個人心境** | 仁者安仁、不憂 | 坦蕩蕩、不憂不懼 | 心境都安心坦然 |

## 考試重點

> [!tip] 必背要點
> 1. **論仁四章的核心邏輯：** 仁者安仁 → 堅守仁德（富貴貧賤取捨） → 克己復禮（實踐方法） → 殺身成仁（最高境界）
> 2. **論孝四章的核心邏輯：** 無違於禮 → 敬的重要性 → 委婉規勸 → 時刻關心
> 3. **論君子八章的核心邏輯：** 四種品德 → 心境坦蕩 → 內省無疚 → 成人之美 → 言行一致 → 義禮孫信 → 自求諸己

> [!tip] 必背注釋
> - **約**：窮困、貧困
> - **知**：通「智」
> - **去**：捨棄
> - **惡**：怎麼、如何（疑問代詞，讀 wū）
> - **終食之間**：一頓飯的時間，指很短的時間
> - **造次**：倉卒、匆忙
> - **顛沛**：窮困、顛沛流離
> - **克己復禮**：抑制自己，使言語行動都合於禮
> - **幾諫**：輕微、婉轉地勸諫
> - **勞**：擔憂
> - **憚**：害怕、畏懼
> - **孫**：通「遜」，謙遜
> - **諸**：即「之於」
> - **病**：憂慮、擔心（亦可解作慚愧、抱怨）

> [!tip] 修辭手法必考
> - **對偶：**「無求生以害仁，有殺身以成仁」；「君子坦蕩蕩，小人長戚戚」
> - **反問：**「君子去仁，惡乎成名」；「為仁由己，而由人乎哉」；「不敬，何以別乎」
> - **排比：**「非禮勿視，非禮勿聽，非禮勿言，非禮勿動」
> - **對比：** 君子 vs 小人；養父母 vs 飼犬馬；富貴 vs 貧賤

## 常見題型

### 一、詞語解釋題

- 解釋「約」、「知」、「去」、「惡」、「幾」、「憚」、「孫」、「諸」等字詞。
- 注意通假字：知→智、孫→遜。

### 二、句意理解題

- 翻譯或解釋特定句子的含義。
- 例如：「不仁者，不可以久處約，不可以長處樂」的深層含義。

### 三、要旨概括題

- 概括某一章或某一組語錄的要旨。
- 例如：概括「論孝」四章行孝的表現。

### 四、比較分析題

- 比較仁者與智者對仁的態度。
- 比較君子與小人的分別（心境、行事、責任感）。
- 比較「養」與「敬」的分別。

### 五、開放式問答題

- 結合生活經驗或個人體會，闡述如何實踐孝道。
- 討論「殺身成仁」在現代社會的意義。
- 引述其他篇章（如《岳陽樓記》、《赤壁懷古》）與本文作比較。

### 六、修辭分析題

- 辨識並分析文中運用的修辭手法（對偶、反問、排比、對比）及其表達效果。

### 七、論述結構分析題

- 分析「領語式」論述結構的特點及好處。

## 重點注釋

### 【論仁】注釋

| 原文 | 注釋 |
|------|------|
| 不可以久處約 | 不可以長久地居於窮困之中。約：窮困、貧困 |
| 知者利仁 | 聰明的人認識仁德對他有長遠而巨大的利益，於是便實行仁德。知：通「智」。利：利用 |
| 處 | 接受 |
| 不以其道得之 | 不以正當的方法得以拋掉它（貧困）。一說「不」字乃衍文 |
| 去 | 捨棄 |
| 惡 | 怎麼、如何，疑問代詞 |
| 終食之間 | 一頓飯的時間，指很短的時間。違：離開、違背 |
| 造次必於是，顛沛必於是 | 在倉卒匆忙、困頓挫折時也一定與仁德同在 |
| 顏淵 | 孔子學生，名回，字子淵 |
| 克己復禮為仁 | 抑制自己，使言語行動都合於禮，就是仁德。復：回復、回歸 |
| 為仁由己，而由人乎哉 | 實踐仁德，要憑自己，難道是憑別人嗎？ |
| 其目 | 它的，指「為仁」的。目：綱目、要目 |
| 非禮勿視… | 不合禮的事不看，不合禮的話不聽，不合禮的話不說，不合禮的事不做 |
| 請事斯語矣 | 請（讓我）實踐（你）這說話 |
| 無求生以害仁，有殺身以成仁 | 沒有為保存性命而損害仁德的，只有犧牲自己以成全仁德的 |

### 【論孝】注釋

| 原文 | 注釋 |
|------|------|
| 孟懿子 | 魯國大夫，姓仲孫，名何忌，「懿」是謚號。其父孟僖子囑其向孔子學禮 |
| 無違 | 不要違背禮節 |
| 樊遲御 | 樊遲（替孔子）驅車。樊遲：孔子學生，名須，字子遲 |
| 孟孫 | 即孟懿子 |
| 生，事之以禮 | （父母）健在，依規定的禮節侍奉他們 |
| 死，葬之以禮，祭之以禮 | （父母）死了，依規定的禮節埋葬他們，祭祀他們 |
| 子游 | 孔子學生，姓言，名偃，字子游 |
| 養（供養） | 粵 [樣]，[joeng6]；普 [yǎng] |
| 養（飼養） | 粵 [仰]，[joeng5]；普 [yǎng] |
| 不敬，何以別乎 | 若不心存敬意，養活父母跟飼養犬馬有甚麼分別呢？ |
| 事父母幾諫 | 侍奉父母，得點到即止地指出，婉轉地勸止。幾：輕微、婉轉 |
| 見志不從，又敬不違，勞而不怨 | 看到自己的意見沒有獲得接納，仍然恭敬地不冒犯他們，雖然擔憂，但不抱怨 |
| 一則以喜，一則以懼 | 一方面因（其高壽）而歡喜，另一方面又因（其壽高）而憂懼 |

### 【論君子】注釋

| 原文 | 注釋 |
|------|------|
| 君子不重則不威 | 君子如果不莊重，就沒有威儀。不重：不莊重 |
| 學則不固 | 兩解：一、所學不會牢固；二、學了就不會閉塞淺陋 |
| 主忠信 | 以忠和信兩種道德為主 |
| 無友不如己者 | 兩解：一、不跟不及自己的人交朋友；二、不跟與自己不同道的人交朋友 |
| 過則勿憚改 | 有了過錯，就不要怕改正。憚：害怕、畏懼 |
| 君子坦蕩蕩，小人長戚戚 | 君子心胸舒坦寬廣，小人卻經常局促憂愁 |
| 司馬牛 | 孔子學生，名耕，字子牛 |
| 內省不疚 | 自己問心無愧 |
| 君子成人之美，不成人之惡 | 君子成全別人的好事，不促成別人的壞事 |
| 小人反是 | 小人卻和這個相反 |
| 君子恥其言而過其行 | 君子會因為自己說得多，但做得少而感到羞恥 |
| 君子義以為質 | 君子處事，以合宜為原則。質：本質 |
| 禮以行之，孫以出之，信以成之 | 依禮節實行它，用謙遜的言語說出它，用誠實的態度完成它。孫：通「遜」 |
| 君子病無能焉 | 君子只會因自己沒有能力而慚愧。病：憂慮、擔心；亦可解作慚愧、抱怨 |
| 君子求諸己，小人求諸人 | 君子要求自己，小人則只會要求別人。諸：即「之於」 |
