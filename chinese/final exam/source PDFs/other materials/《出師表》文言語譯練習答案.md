# 諸葛亮《出師表》文言語譯練習答案

姓名 :             班別及班號 :   (   )   日期:          成績:        /66

## 甲、試解釋以下文句中的粗體字，並把答案寫在橫線上。（66 分）

1. 先帝創業未半，而中道崩殂。 崩殂 : 古代皇帝死亡

2. 今天下三分，益州疲弊，此誠危急存亡之秋也！ 誠 : 實在

3. 今天下三分，益州疲弊，此誠危急存亡之秋也！ 秋 : 關鍵時刻

4. 然侍衞之臣，不懈於內；忠志之士，忘身於外者。 懈 : 懈怠、怠惰

5. 蓋追先帝之殊遇，欲報之於陛下也。 蓋 : 這是因為

6. 蓋追先帝之殊遇，欲報之於陛下也。 殊 : 特殊的、特別的

7. 誠宜開張聖聽，以光先帝遺德，恢弘志士之氣。 開張 : 展開、擴大

8. 誠宜開張聖聽，以光先帝遺德，恢弘志士之氣。 光 : 發揚、弘揚

9. 誠宜開張聖聽，以光先帝遺德，恢弘志士之氣。 恢弘 : 激勵

10. 誠宜開張聖聽，以光先帝遺德，恢弘志士之氣。 氣 : 士氣

11. 不宜妄自菲薄，引喻失義，以塞忠諫之路也。 妄 : 胡亂

12. 不宜妄自菲薄，引喻失義，以塞忠諫之路也。 菲薄 : 輕視

13. 不宜妄自菲薄，引喻失義，以塞忠諫之路也。 引 : 徵引

14. 不宜妄自菲薄，引喻失義，以塞忠諫之路也。 義 : 義理、原則

15. 不宜妄自菲薄，引喻失義，以塞忠諫之路也。 塞 : 堵塞

16. 宮中、府中，俱為一體。 俱 : 都是

17. 陟罰臧否，不宜異同。 陟 : 晉升

18. 陟罰臧否，不宜異同。 臧 : 良善、善良

19. 陟罰臧否，不宜異同。 否 : 醜惡、邪惡

20. 若有作姦、犯科。 姦 : 同「奸」，邪惡之事

21. 若有作姦、犯科。 科 : 法令、法律

22. 及為忠善者，宜付有司，論其刑賞，以昭陛下平明之治。 有司 : 專門主管的官員、負責的官員

23. 及為忠善者，宜付有司，論其刑賞，以昭陛下平明之治。 昭 : 彰顯

24. 以昭陛下平明之治。 平明 : 公正嚴明

25. 不宜偏私，使內外異法也。 偏私 : 偏袒徇私

26. 此皆良實，志慮忠純，是以先帝簡拔以遺陛下。 良實 : 善良忠實

27. 此皆良實，志慮忠純，是以先帝簡拔以遺陛下。 志慮 : 志向和思想

28. 是以先帝簡拔以遺陛下。 簡 : 通「揀」，揀選、挑選

29. 是以先帝簡拔以遺陛下。 拔 : 提拔

30. 是以先帝簡拔以遺陛下。 遺 : 留給

31. 悉以咨之，然後施行。 悉 : 全部

32. 悉以咨之，然後施行。 咨 : 通「諮」，諮詢

33. 必能裨補闕漏，有所廣益。 裨 : 補救

34. 必能裨補闕漏，有所廣益。 闕 : 缺失、不足

35. 性行淑均，曉暢軍事。 淑均 : 善良公正

36. 性行淑均，曉暢軍事。 曉暢 : 精通

37. 先帝稱之曰「能」。 稱 : 稱讚、稱許

38. 是以眾議舉寵為督。 舉 : 推舉

39. 必能使行陣和睦，優劣得所。 行陣 : 軍隊

40. 親賢臣，遠小人。 遠 : 疏遠、遠離

41. 此悉貞良死節之臣。 貞良死節 : 忠誠賢良，能為堅守節操而死

42. 臣本布衣，躬耕於南陽。 布衣 : 平民、百姓

43. 臣本布衣，躬耕於南陽。 躬 : 親自、親身

44. 苟全性命於亂世，不求聞達於諸侯。 苟 : 姑且

45. 先帝不以臣卑鄙。 卑鄙 : 身份卑微見識鄙陋

46. 猥自枉屈，三顧臣於草廬 猥 : (謙詞)，降低身份

47. 猥自枉屈，三顧臣於草廬。 枉屈 : 枉自委屈

48. 遂許先帝以驅馳。 遂 : 於是

49. 遂許先帝以驅馳。 驅馳 : 奔走效勞

50. 後值傾覆，受任於敗軍之際，奉命於危難之間。 值 : 遇到、適逢

51. 爾來二十有一年矣。 爾來 : 從那時以來

52. 爾來二十有一年矣。 有 : 又

53. 受命以來，夙夜憂歎，恐託付不效，以傷先帝之明。 夙 : 早上

54. 故五月渡瀘，深入不毛。 不毛 : 土地貧瘠之地、荒蕪之地

55. 庶竭駑鈍，攘除姦凶，興復漢室。 庶 : 願意

56. 庶竭駑鈍，攘除姦凶，興復漢室。 竭 : 竭盡

57. 庶竭駑鈍，攘除姦凶，興復漢室。 駑 : 劣馬

58. 庶竭駑鈍，攘除姦凶，興復漢室。 攘 : 攘除、剷除

59. 至於斟酌損益，進盡忠言。 斟酌 : 仔細考慮

60. 若無興德之言，則責攸之、禕、允等之慢，以彰其咎。 興德 : 發揚德政

61. 若無興德之言，則責攸之、禕、允等之慢，以彰其咎。 彰 : 揭示

62. 若無興德之言，則責攸之、禕、允等之慢，以彰其咎。 咎 : 過失

63. 陛下亦宜自謀。 謀 : 思考、考慮

64. 以諮諏善道，察納雅言，深追先帝遺詔。 諏 : 諮詢、詢問

65. 以諮諏善道，察納雅言，深追先帝遺詔。 雅 : 正確合理的

66. 今當遠離，臨表涕零，不知所言！ 涕 : 眼淚

完
