甲、試解釋以下文句中的粗體字，並把答案寫在橫線上。（35 分）

1.   六國破滅，非兵不利，戰不善，弊在賂秦。             弊 : 弊病、過失


2.   賂秦而力虧，破滅之道也。                    賂 : 賄賂


3.   賂秦而力虧，破滅之道也。                    虧 : 虧損、消耗、衰弱


4.   或曰：「六國互喪，率賂秦耶？」                 或 : 有人


5.   或曰：「六國互喪，率賂秦耶？」                 率 : 全部、全都


6.   或曰：「六國互喪，率賂秦耶？」                 耶 : 嗎


7.   蓋失強援，不能獨完，故曰「弊在賂秦」也。            蓋 : 因為、原因在於


8.   諸侯之所亡與戰敗而亡者，其實亦百倍。              亡 : 喪失


9.   則秦之所大欲，諸侯之所大患，固不在戰矣。            患 : 憂患、禍害


10. 則秦之所大欲，諸侯之所大患，固不在戰矣。             固 : 固然、當然、本來


11. 思厥先祖父。                           厥 : 同「其」，他們的


12. 子孫視之不甚惜，舉以予人，如棄草芥。               舉 : 拿來


13. 然則諸侯之地有限，暴秦之欲無厭。                 厭 : 通「饜」，滿足


14. 奉之彌繁，侵之愈急，故不戰而強弱勝負已判矣。           彌 : 越來越、愈來愈、愈加


15. 至於顛覆，理固宜然。                       固 : 固然、當然、本來


16. 古人云：「以地事秦，猶抱薪救火，薪不盡，火不滅。」        事 : 討好


17. 古人云：「以地事秦，猶抱薪救火，薪不盡，火不滅。」        薪 : 柴薪、柴木

18. 齊人未嘗賂秦，終繼五國遷滅，何哉？          嘗 : 曾經


19. 與嬴而不助五國也。五國既喪，齊亦不免矣。       與 : 親附


20. 與嬴而不助五國也。五國既喪，齊亦不免矣。       既 : 已經


21. 燕趙之君，始有遠略，能守其土，義不賂秦。       義 : (守着)原則


22. 是故燕雖小國而後亡，斯用兵之效也。          斯 : 這是


23. 至丹以荊卿為計，始速禍焉。              始 : 才


24. 後秦擊趙者再，李牧連卻之。              卻 : 擊退


25. 洎牧以讒誅，邯鄲為郡，惜其用武而不終也。       洎 : 及至、等到


26. 且燕趙處秦革滅殆盡之際。               革 : 革除


27. 且燕趙處秦革滅殆盡之際。               殆 : 差不多、幾乎


28. 可謂智力孤危，戰敗而亡，誠不得已。          誠 : 實在、確實


29. 向使三國各愛其地。                  向使 :假使、如果


30. 刺客不行，良將猶在，則勝負之數。           數 : 運數、命數、命運


31. 存亡之理，當與秦相較，或未易量。           當 : 倘若、假如、假若


32. 存亡之理，當與秦相較，或未易量。           量 : 估量、計算、判斷


33. 以事秦之心，禮天下之奇才。              禮 : (動詞)，禮待


34. 並力西嚮，則吾恐秦人食之不得下嚥也。         嚮 : 通「向」，往


35. 有如此之勢，而為秦人積威之所劫，日削月割，以趨於亡。 趨 : 走向、步向
