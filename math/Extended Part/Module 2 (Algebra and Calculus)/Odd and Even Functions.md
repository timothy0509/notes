# Odd and Even Functions

## Definition

A function $f(x)$ is **even** if $f(-x) = f(x)$ for all $x$ in its domain.

A function $f(x)$ is **odd** if $f(-x) = -f(x)$ for all $x$ in its domain.

## Graphical Symmetry

- **Even functions**: symmetric about the $y$-axis
- **Odd functions**: symmetric about the origin (rotation by $180^\circ$)

## Examples

| Function | Type | Check |
|----------|------|-------|
| $f(x)=x^2$ | Even | $(-x)^2 = x^2$ |
| $f(x)=x^3$ | Odd | $(-x)^3 = -x^3$ |
| $f(x)=\cos x$ | Even | $\cos(-x)=\cos x$ |
| $f(x)=\sin x$ | Odd | $\sin(-x)=-\sin x$ |
| $f(x)=|x|$ | Even | $|-x| = |x|$ |
| $f(x)=x$ | Odd | $(-x) = -x$ |
| $f(x)=x^2+1$ | Even | $(-x)^2+1 = x^2+1$ |

## Absolute Value Function

The absolute value function $f(x)=|x|$ is an example of an even function:
$$
|x| = \begin{cases}
x & x \ge 0 \\
-x & x < 0
\end{cases}
$$

## Properties

- Sum of two even functions is even
- Sum of two odd functions is odd
- Product of two even functions is even
- Product of two odd functions is even
- Product of an even and an odd function is odd
