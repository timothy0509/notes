# Differentiation of a Function

## Basic Differentiation Rules

| Rule | Formula |
|---|---|
| Constant | $(C)' = 0$ |
| Power | $(x^n)' = nx^{n-1}$ |
| Addition | $(u+v)' = u' + v'$ |
| Product | $(uv)' = u'v + uv'$ |
| Quotient | $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$ |
| Chain | $\dfrac{dy}{dx} = \dfrac{dy}{du} \cdot \dfrac{du}{dx}$ |

## Derivatives of Elementary Functions

| Function | Derivative |
|---|---|
| $C$ (constant) | $0$ |
| $x^n$ | $nx^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $\log_a x$ | $\dfrac{1}{x \ln a}$ |
| $a^x$ | $a^x \ln a$ |

## Notes

- Implicit differentiation **not required**
- Logarithmic differentiation **not required**
- Algebraic functions include polynomials, rational functions, power functions $x^\alpha$, and their combinations via $+,-,\times,\div,\circ$
