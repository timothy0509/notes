# Basic Definition and Properties of the Normal Distribution

## Continuous Random Variables

A continuous random variable takes values in an interval. Probabilities are given by areas under a probability density function (pdf).

Formulae from [[Probability Distribution, Expectation and Variance]] also apply to continuous random variables.

## Normal Distribution

$X \sim N(\mu, \sigma^2)$ with pdf:

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}$$

Derivations of the mean and variance are **not required**.

## Properties

| Property | Description |
|---|---|
| Shape | Bell-shaped, symmetrical about $\mu$ |
| Centre | Mean = Mode = Median |
| Spread | $\sigma$ determines flatness (larger $\sigma$ $\implies$ flatter/wider) |
| Area | Total area under curve $= 1$ |
| Domain | $x \in (-\infty, \infty)$ |
