# Standardisation of a Normal Variable

## Standardisation Formula

If $X \sim N(\mu, \sigma^2)$, then:

$$Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$

$Z$ is the **standard normal variable** (mean 0, variance 1).

## Using the Standard Normal Table

The table gives $P(Z < z)$ (cumulative probability) for $z \ge 0$.

| Probability | Method |
|---|---|
| $P(Z < a)$ | Read directly from table |
| $P(Z > a)$ | $1 - P(Z < a)$ |
| $P(a < Z < b)$ | $P(Z < b) - P(Z < a)$ |
| $P(Z < -a)$ | $P(Z > a) = 1 - P(Z < a)$ |
