# Discrete Random Variables

## Definition

A **discrete random variable** $X$ takes on a countable set of values, each with a certain probability.

- $X$ is a function mapping outcomes of a random experiment to real numbers
- The set of possible values is finite or countably infinite

## Example

Tossing a coin 3 times: let $X$ = number of heads.

$$X \in \{0, 1, 2, 3\}$$
