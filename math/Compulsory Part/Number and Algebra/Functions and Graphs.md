# Functions and Graphs

## Intuitive Concepts of Functions
A function $f: A\to B$ maps each element $x$ in domain $A$ to exactly one element $f(x)$ in co-domain $B$.
- Domain: set of all inputs
- Co-domain: set of possible outputs
- Independent variable ($x$), dependent variable ($y=f(x)$)

## Function Notation
Representations: tabular, algebraic ($f(x)=ax^2+bx+c$), graphical.

## Quadratic Function Graphs
$$f(x)=ax^2+bx+c \quad (a\neq0)$$

Features:
- Vertex: turning point
- Axis of symmetry: $x=-\frac{b}{2a}$
- Direction of opening: upward if $a>0$, downward if $a<0$
- $y$-intercept: $c$
- $x$-intercepts: roots of $ax^2+bx+c=0$

## Maximum and Minimum Values
### Graphical Method
Read from the vertex of the parabola.

### Algebraic Method (Completing the Square)
$$y = a(x-h)^2 + k$$
- Vertex at $(h,k)$
- If $a>0$: minimum value $k$ at $x=h$
- If $a<0$: maximum value $k$ at $x=h$$
