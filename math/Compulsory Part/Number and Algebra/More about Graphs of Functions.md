# More about Graphs of Functions

## Sketching and Comparing Functions
Compare: domains, existence of max/min values, symmetry, periodicity.

| Function Type | Example | Domain | Shape |
|---------------|---------|--------|-------|
| Constant | $y=c$ | $\mathbb{R}$ | Horizontal line |
| Linear | $y=mx+c$ | $\mathbb{R}$ | Straight line |
| Quadratic | $y=ax^2+bx+c$ | $\mathbb{R}$ | Parabola |
| Trigonometric | $y=\sin x$, $\cos x$, $\tan x$ | $\mathbb{R}$ (except $\tan x$) | Periodic waves |
| Exponential | $y=a^x$ | $\mathbb{R}$ | Growth/decay curve |
| Logarithmic | $y=\log_a x$ | $x>0$ | Log curve |

## Solving $f(x)=k$ Using Graphs
The solutions are the $x$-coordinates of intersection points of $y=f(x)$ and $y=k$.

## Solving Inequalities Using Graphs
For $f(x) > k$, $f(x) < k$, $f(x) \geq k$, $f(x) \leq k$:
Read the $x$-range where the graph of $y=f(x)$ lies above/below $y=k$.

## Transformations of Functions

| Transformation | Effect on $y=f(x)$ |
|----------------|-------------------|
| $f(x)+k$ | Vertical shift (up $k>0$, down $k<0$) |
| $f(x+k)$ | Horizontal shift (left $k>0$, right $k<0$) |
| $k f(x)$ | Vertical stretch/compression (by factor $k$) |
| $f(kx)$ | Horizontal stretch/compression (by factor $1/k$) |
