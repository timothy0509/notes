# Key Formulas Reference

> [!abstract] Quick Reference
> All essential formulas for the BAFS Accounting Strand examination in one place.

---

## Personal Financial Management

| Formula | Expression |
|---------|------------|
| **Future Value** | $FV = PV \times (1 + r)^n$ |
| **Present Value** | $PV = \frac{FV}{(1 + r)^n}$ |
| **Net Present Value** | $NPV = \sum \frac{CF_t}{(1+r)^t} - \text{Initial Investment}$ |
| **Effective rate** | $r_{eff} = (1 + \frac{r_{nom}}{m})^m - 1$ |

## Financial Analysis Ratios

### Profitability

| Ratio | Formula |
|-------|---------|
| Mark-up | $\frac{\text{Gross profit}}{\text{COGS}} \times 100\%$ |
| Gross profit ratio | $\frac{\text{Gross profit}}{\text{Sales}} \times 100\%$ |
| Net profit ratio | $\frac{\text{Net profit before tax}}{\text{Sales}} \times 100\%$ |
| ROCE | $\frac{\text{PBIT}}{\text{Average capital employed}} \times 100\%$ |

### Liquidity

| Ratio | Formula |
|-------|---------|
| Current ratio | $\frac{\text{Current assets}}{\text{Current liabilities}}:1$ |
| Quick ratio | $\frac{\text{Current assets} - \text{Inventory}}{\text{Current liabilities}}:1$ |

### Management Efficiency

| Ratio | Formula |
|-------|---------|
| Inventory turnover | $\frac{\text{COGS}}{\text{Average inventory}}$ |
| Avg receivables collection period | $\frac{\text{Average trade receivables}}{\text{Credit sales}} \times 365$ |
| Receivables turnover | $\frac{\text{Credit sales}}{\text{Average trade receivables}}$ |
| Avg payables repayment period | $\frac{\text{Average trade payables}}{\text{Credit purchases}} \times 365$ |
| Payables turnover | $\frac{\text{Credit purchases}}{\text{Average trade payables}}$ |
| Total assets turnover | $\frac{\text{Sales}}{\text{Total assets}}$ |

### Solvency

| Ratio | Formula |
|-------|---------|
| Gearing ratio | $\frac{\text{NCL} + \text{Preference shares}}{\text{NCL} + \text{Shareholders' equity}} \times 100\%$ |

### Return on Investment

| Ratio | Formula |
|-------|---------|
| EPS | $\frac{\text{Net profit after tax} - \text{Preference dividend}}{\text{Number of ordinary shares}}$ |
| Dividend cover | $\frac{\text{Net profit after tax} - \text{Preference dividend}}{\text{Ordinary dividend paid}}$ |
| P/E ratio | $\frac{\text{Market price per share}}{\text{EPS}}$ |

## Cost Accounting

### CVP Analysis

| Formula | Expression |
|---------|------------|
| Contribution per unit | $\text{Selling price} - \text{Variable cost}$ |
| Break-even (units) | $\frac{\text{Fixed costs}}{\text{Contribution per unit}}$ |
| Break-even (\$) | $\frac{\text{Fixed costs}}{\text{Contribution/sales ratio}}$ |
| Margin of safety | $\frac{\text{Actual sales} - \text{Break-even sales}}{\text{Actual sales}} \times 100\%$ |
| Target profit (units) | $\frac{\text{Fixed costs} + \text{Target profit}}{\text{Contribution per unit}}$ |
| Weighted avg contribution | $\sum (\text{Contribution per unit} \times \text{Sales mix proportion})$ |

### Depreciation

| Method | Formula |
|--------|---------|
| Straight-line | $\frac{\text{Cost} - \text{Residual value}}{\text{Useful life}}$ |
| Reducing balance | $\text{NBV at start of year} \times \text{Rate\%}$ |
| Units of production | $\frac{\text{Cost} - \text{Residual value}}{\text{Total estimated units}} \times \text{Units produced}$ |

### Other

| Formula | Expression |
|---------|------------|
| Profit (incomplete records) | $\text{Closing capital} - \text{Opening capital} + \text{Drawings} - \text{Additional capital}$ |
| Absorption rate | $\frac{\text{Budgeted fixed production overheads}}{\text{Budgeted activity level}}$ |
| Profit difference (M vs A) | $\text{Change in inventory units} \times \text{Fixed overhead rate per unit}$ |

## Tips for Using This Reference

> [!tip] Before the Exam
> 1. Memorise all formulas — write them down as soon as the exam starts
> 2. Know when to use each formula
> 3. Practice applying them to different scenarios
> 4. Check units (days vs months, % vs times)

> [!warning] During the Exam
> - Always show the formula before substituting numbers
> - Round to 2 decimal places unless specified otherwise
> - Double-check calculations
> - State the answer clearly with units
