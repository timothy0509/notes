# Trial Balance

> [!abstract] Overview
> A trial balance lists all ledger account balances to check that total debits equal total credits. It is a vital step before preparing financial statements, but it has important limitations.

---

## 1. Purpose and Function

> [!note] Definition
> A **trial balance** is a list of all ledger account balances at a particular date, arranged with debit balances on one side and credit balances on the other, to verify the arithmetical accuracy of the double entry system.

### Functions

1. **Check arithmetical accuracy** — total debits must equal total credits
2. **Basis for preparing financial statements** — provides the figures needed
3. **Detect certain errors** — some errors cause the TB to not balance

> [!tip] Exam Tip
> Always list accounts in the order: Non-current assets → Current assets → Liabilities → Capital → Drawings → Revenue → Expenses. This mirrors the financial statement format.

---

## 3. Limitations

> [!warning] Errors NOT Detected by Trial Balance
> A trial balance will still balance even if these errors exist:

| Error Type | Example |
|------------|---------|
| **Complete omission** | Transaction not recorded at all |
| **Commission** | Posted to the wrong account of the same type |
| **Principle** | Posted to the wrong class of account (e.g. expense treated as asset) |
| **Original entry** | Wrong amount recorded in both debit and credit |
| **Compensating** | Two errors cancel each other out |
| **Reversal of entries** | Debited and credited the wrong way round |

> [!important] Key Point
> A balanced trial balance does **NOT** guarantee error-free books. It only confirms that total debits = total credits. Additional controls (e.g. bank reconciliation, suspense accounts) are needed.

---

## 4. Suspense Account

When a trial balance does not balance, the difference is placed in a **suspense account** to temporarily force it to balance. The suspense account is eliminated once the errors are identified and corrected.

| Scenario | Action |
|----------|--------|
| Dr total > Cr total | Credit suspense account with the difference |
| Cr total > Dr total | Debit suspense account with the difference |
| Error found | Correcting entry involves the suspense account |
| All errors found | Suspense account balance = zero |
